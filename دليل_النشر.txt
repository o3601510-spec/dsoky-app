📱 حزمة تطبيق شبكة أبو إسماعيل — للنشر على GitHub Pages
════════════════════════════════════════════════════════════

■ ليه التطبيق بيتنشر على GitHub Pages (HTTPS) مش على الراوتر؟
متصفح كروم على أندرويد **يمنع نافذة التثبيت على اتصال HTTP**
(قاعدة أمان). شبكة الهوتسبوت بتشتغل HTTP → مستحيل تظهر نافذة
«إضافة إلى الشاشة الرئيسية» من صفحة الراوتر مهما كان الكود.
الحل: صفحة التطبيق على HTTPS (GitHub Pages) → النافذة تظهر
وتتثبت الأيقونة، وبعدين الأيقونة بتفتح التطبيق وهو بيحولك
لصفحة الشبكة مباشرة.

■ طريقة النشر (خطوة خطوة):
1) ادخل github.com وسجّل دخول بحسابك (نفس حساب
   o3601510-spec — اللي عليه صفحة الماسح).
2) اعمل New repository:
   - الاسم: dsoky-app
   - Public
   - Create repository
3) Upload files: ارفع من الحزمة دي:
   - index.html
   - manifest.json
   - sw.js
   - مجلد icons/ (كله — 5 ملفات)
4) Commit changes.
5) من إعدادات الريبو: Settings ← Pages ← Source: Deploy
   from a branch ← Main ← / (root) ← Save.
6) استنى دقيقة، والتطبيق يبقى على:
   https://o3601510-spec.github.io/dsoky-app/

■ اختبار:
افتح الرابط على موبايل أندرويد (كروم) → اضغط «تثبيت التطبيق
الآن» → تظهر نافذة «إضافة إلى الشاشة الرئيسية» → تثبيت ✔
الأيقونة هتظهر على الشاشة وبعدها بتفتح التطبيق.

■ ملاحظات:
- زر «ثبّت التطبيق» على صفحات الهوتسبوت (login/status) بينقل
  تلقائيًا لرابط التطبيق ده — فالنشر ده شرط شغل الزر.
- لو حبيت تستضيف التطبيق على دومين تاني (مثلًا khatwatuk.com
  أو أي استضافة HTTPS): ارفع نفس الملفات هناك وغيّر الرابط
  في ملفي login.html و status.html (سطر واحد في كل ملف:
  https://o3601510-spec.github.io/dsoky-app/).
- آيفون: مفيش نافذة تثبيت رسمية في سفاري إطلاقًا — التطبيق
  بيعرض خطوة واحدة مختصرة (مشاركة ← إضافة للشاشة الرئيسية).
- لو عايزني أنشر أنا بنفسي: ابعتلي GitHub Token (صلاحيات
  repo فقط) — أو لو عندك gh CLI على جهازك اعمله auth وأنا
  أتكفل بالباقي.
